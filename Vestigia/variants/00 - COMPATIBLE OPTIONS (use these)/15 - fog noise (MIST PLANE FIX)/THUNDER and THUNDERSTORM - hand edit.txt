THUNDER / THUNDERSTORM - hand edit (Vestigia's copies of these files are not in the repo)

For each file in  lml/Vestigia/active/ess/ : open in Notepad. In the FIRST region
(<region name="GLOBAL">, i.e. the FIRST time each setting appears - NOT the second/URBAN one),
replace the whole line of each setting below with the vanilla line. Save.
If a file doesn't exist in your active/ess, skip it (the game then already uses vanilla).
Or: upload your Vestigia w_thunder.xml / w_thunderstorm.xml to the repo and Claude patches them.
