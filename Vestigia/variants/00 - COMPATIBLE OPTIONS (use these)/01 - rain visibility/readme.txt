RAIN VISIBILITY - how solid/visible the falling rain drops are.
Changes only the 5 *_render_drop files. Splashes, mist fix, shower fix etc. are not affected.

HOW TO USE: pick ONE option folder.
  - files directly in it  -> copy to  Vestigia/active/ess   (replace)
  - files in its str/      -> copy to  Vestigia/active/str   (replace)

0 - default (balanced)   INSTALLED NOW. Tuned while DLSS was on: more solid, slightly darker drops.
1 - softer (previous)    More see-through.
2 - stronger             Most solid and darkest; easiest to see against clouds.
3 - pure Rain Particles Fix   The original Rain Particles Fix drop look, no extra tuning.
                         Try this (or 1) if you play WITHOUT DLSS: the tuning in 0/2 was
                         compensating for DLSS smearing the rain.
