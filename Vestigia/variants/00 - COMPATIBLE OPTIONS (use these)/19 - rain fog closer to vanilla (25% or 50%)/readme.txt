RAIN FOG CLOSER TO VANILLA - only the RAIN weather (w_rain.xml). Drizzle, Shower etc. are not changed.
Fog thickness / height / falloff move 25% or 50% of the way from Vestigia toward vanilla (per time of day).

  25%: fog thickness 0.00592 (6.8x vanilla) -> 0.00465 (5.4x vanilla);  height 1000 -> 865 (vanilla 462)
  50%: fog thickness 0.00592 (6.8x vanilla) -> 0.00339 (3.9x vanilla);  height 1000 -> 731 (vanilla 462)

1 - 25% (no wind)              4 - 50% (no wind)
2 - 25% + gentle wind (16-1)   5 - 50% + gentle wind (16-1)
3 - 25% + strong wind (16-2)   6 - 50% + strong wind (16-2)
0 - current (installed) = undo.

HOW: copy w_rain.xml from ONE option folder to  Vestigia/active/ess  (replace).
Using option 16 (wind)? Install option 16 first, then copy w_rain.xml from the matching wind version here.
