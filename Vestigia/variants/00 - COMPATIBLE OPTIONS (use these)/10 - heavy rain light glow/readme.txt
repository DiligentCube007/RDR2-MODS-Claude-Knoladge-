HEAVY RAIN LIGHT GLOW - big drops in Rain, Shower, Thunderstorm and Hurricane glow less
when you look toward the sun, lamps or lanterns. Drop size, amount and look elsewhere unchanged.
  translucency          = how much light shines THROUGH the drop toward you
  wrapLightingTerm      = how much light wraps around the drop edges
  localLightsMultiplier = how strongly lamps/lanterns/fire light up the drops

OPTION A - copy files (easiest):
  Pick ONE option folder. Files directly in it -> Vestigia/active/ess (replace),
  files in its str/ subfolder -> Vestigia/active/str (replace).
  '0 - current (installed)' puts back what you have now.

OPTION B - edit by hand (use this if you already picked another rain preset in 01 or 08,
  so you keep that preset and only add this change):
  Open '1 - less glow/lines changed.txt'. For each file listed, open it in Notepad,
  find the setting and change the number to the new value. Save.

Affects: Rain, Shower, Thunderstorm, Hurricane (4 files). Overwritten if you later copy a preset
from 01 or 08 - re-apply after (option B is easiest).
