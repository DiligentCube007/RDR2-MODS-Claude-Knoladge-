WEATHER SPEED - how long each weather lasts before it can change (Vestigia "Weather System" module).
Same as Vestigia's own 'weather system speed' variants, but built from YOUR active file
(Vestigia's variant files have a typo: a second SUNNY node instead of SUNNYSEATTLE).

HOW TO USE: copy weatherGraph.xml from ONE option folder to  Vestigia/active/wea  (replace).

0 - default (100)   INSTALLED NOW
1 - slowest (400)   4x longer than default
2 - slow (200)      2x longer  <- good next step, RW also holds weather longer
3 - fast (50)       about vanilla speed
4 - fastest (25)

Note: the RW .asi also controls how long weather lasts (its Persistence Presets, AgeScale).
